# Component Architecture Specification

> **Target Audience:** 소프트웨어 아키텍트, 기술 면접관  
> **Overview:** 시스템을 구성하는 핵심 계층별 단일 책임(Single Responsibility), 입출력 규격 및 Fail-Closed 불변식 정의.

---

## 1. 계층별 컴포넌트 매트릭스

| 컴포넌트 계층 | 담당 역할 | 입력 (Input) | 출력 (Output) | 핵심 불변식 및 안전장치 |
| :--- | :--- | :--- | :--- | :--- |
| **Realtime Collector** | 15:20 후보 스캔, 단면 수집, 12bp 틱비용 필터링 | 전시장 실시간 시세, 10호가, 잠정수급 | `archive.parquet`, `orderbook/` | 15:20~15:30 외 실행 거부, 정상률 < 99% 시 저장 거부 |
| **Inference Engine** | 28차원 PIT 피처 산출, 5-Seed LGBM 앙상블 추론 | 당일 15:20 스냅샷, 과거 일별 패널, 모델 번들 | `topk_decisions.parquet` (Top-3) | 결측치 플레이스홀더 금지, 적격 부족 시 전액 현금 보유 |
| **Close Finalizer** | 15:30:30 단일가 체결 3중 검증 및 종가 갱신 | KIS 체결가 TR, 10호가 TR | `archive.parquet` (종가_확정=True) | 시계, 마감코드('3'), 체결가 일치 3중 통과 시만 확정 |
| **Paper Broker** | 실주문 없이 WebSocket 체결틱 기반 가상 체결 | 추론 결과, 확정 종가, KIS 실시간 틱 | 가상 체결/포지션/원장 (`data/paper/`) | 사후 갭 필터 배제, 실시간 틱 기반 슬리피지 전액 반영 |
| **ML & Research** | CPCV(8,2) 검증, 비용 스트레스 분석, 번들 빌드 | 10년치 전종목 일별 수정주가 패널 | 학습 모델 번들, 성능 보고서 | `date_demeaned` 타깃 학습, 28개 무누출 OOF 경로 검증 |
| **Cost Engine** | 법정거래세 스케줄, 호가단위 틱비용 산출 | 주가, 거래일, 시장구분(KOSPI/KOSDAQ) | 종목별 틱비용(bp), 거래세율(bp) | KRX 호가단위 개편(2023-01) 소급 적용 및 법정세율 반영 |
| **Data Lake Store** | Parquet 코덱, 패널 정합성 복구, 원자적 I/O | 원천 시세 데이터, 일중 분봉/틱 | 컬럼형 파티션 스토리지 | 임시 파일 쓰기 후 OS `rename` 원자적 교체 (`atomic_write`) |
| **Multi-Broker Gateway** | 4개 증권사 Rate Limit 제어 및 API 통신 | 증권사별 요청 파라미터 | 정규화된 시세/호가/차트 데이터 | 키움(스캔), KIS(단면), LS(분봉), 토스(쿼트) 특화 분산 |

## 2. 핵심 컴포넌트 세부 명세

### 1) Realtime Collector
* **책임**: 15:20:00에 발화하여 키움 API로 당일 2%~10% 상승 종목을 스캔하고, KIS API로 현재가·10호가·잠정수급을 병렬 수집.
* **불변 규칙**: 15:20~15:30 외 실행 거부, 주가대별 1틱 비용 12.0bp 초과 및 상한가 제외, 단면 정상률 99% 미만 시 저장 차단.

### 2) Inference Engine
* **책임**: 15:21:00에 스냅샷을 읽어 28차원 피처(`TOPK_FEATURE_COLS_V2`)를 산출하고, 5개 시드 LightGBM 앙상블로 Top-3 종목을 선정.
* **불변 규칙**: 결측치 발생 시 플레이스홀더를 채우지 않고 즉시 Fail-Closed 예외 발생, 적격 종목 부족 시 전액 현금 보유.

### 3) Close Finalizer
* **책임**: 15:30:30에 장마감 단일가 매매 결과를 수집하여 3중 Fail-Closed 게이트를 통과한 경우에만 공식 종가로 확정.
* **불변 규칙**: 체결 시각(>=15:30), 단일가 마감코드('3'), 현재가-호가 체결가 일치가 모두 참이어야 함.

### 4) Paper Broker
* **책임**: 실계좌 주문 전송 없이 정수 수량을 계산하여 진입(15:30)하고, WebSocket 실시간 체결틱(`H0STCNT0`)을 바탕으로 익일 09:00 시초가에 기계적 전량 청산.
* **불변 규칙**: 사후 갭 필터 전면 배제 (슬리피지 포함 실체결 반영).

### 5) ML Research & Validation Engine
* **책임**: 8개 시계열 블록을 28개 조합으로 분할하는 Combinatorial Purged CV(8,2)를 통해 시계열 과적합을 차단하고, 모델 번들 및 검증 리포트 산출.
* **불변 규칙**: 당일 단면 평균을 차감한 `date_demeaned` 타깃으로 순수 횡단면 상대 랭킹 학습.
