## 핵심 질문에 대한 정량적 답변

### 질문 1. 현재 전략에 실제 alpha가 존재하는가?
**답변: 통계적으로 유의미한 실거래 알파는 사실상 '비용 후 제로 알파(Zero-Alpha)'에 수렴한다.**

1. **무조건부 시장 기저율(Base Rate)**: 
   - 전수 유동성 유니버스(59만개 봉)의 오버나이트 갭은 Gross +18.9bp에 불과하다. 
   - 2026년 기준 실측 거래비용(세금 20bp + 스프레드 26bp = 46bp)을 차감하면 **Net −27.1bp/일 (t = −15.88)**로 구조적 적자이다.
2. **기존 운영자 스크린(`>=10%`)**: 
   - Gross +16.9bp, **Net −29.1bp/일 (t = −8.58)**로 시장 평균보다 오히려 나쁘다.
3. **ML 랭커 적용 실측치(OOF / 잠긴 OOS)**: 
   - D+1 시가 매도 기준: 전체 2,058일 동안 **+1.6bp/일 (t = 0.22, Sharpe 0.22)**로 사실상 breakeven.
   - D+1 TP 5% + MOC 기준: **+15.1bp/일 (t = 1.1)**이나 OOS에서는 **−5.6bp**로 무효화.
4. **결론**: 과거 보고서의 연 30~50% 수익률은 (1) 비현실적인 20bp 비용 가정, (2) 상한가(+30%) 미체결 종목 포함, (3) 운영자 재량 고점 매도가 혼입된 Journaled 라벨의 잔재가 만든 **신기루(Phantom Alpha)**였다.

### 질문 2. alpha는 어디에서 발생하는가?
**답변: 알파는 오직 `Close(T) → Open(T+1)` (오버나이트 갭)에만 존재하며, 장중 및 다일 연속성에는 전혀 존재하지 않는다.**

- **Universe**: 알파 없음 (−27bp 기저율 적자).
- **Ranking**: 인샘플에서는 강력하나(Rank IC 0.37, 스프레드 414bp), OOS에서는 부호 반전(-0.18)으로 알파 기여 소멸.
- **Overnight Gap**: **유일하게 양(+)의 Gross 기대값이 발생하는 구간** (+18bp ~ +31bp).
- **D+1 Intraday**: **가장 파괴적인 마이너스 알파 구간** (D1 Open → D1 Close 점증 기대수익: **−61.1bp/일, t = −10.74, 승률 39.5%**).
- **D+2**: 추가 알파 전무 (점증 수익률 **−15.6bp/일, t = −2.61**).
- **D+3**: 추가 알파 전무 (점증 수익률 **−8.9bp/일, t = −1.62**).

### 질문 3. 현재 `종가 → 익일 시가` 전략을 유지할 근거가 있는가?
**답변: 그렇다 (KEEP). 다만 독자적 알파가 뛰어나서가 아니라, 고정 청산 공간에서 '유일하게 파멸을 피하는 baseline'이기 때문이다.**

- 고정 청산 비교:
  - D+1 Open: **+1.6 bp (OOS +21.6 bp)**
  - D+1 Close: **−42.0 bp (OOS −65.0 bp)**
  - D+2 Close: **−58.0 bp (OOS −91.0 bp)**
  - D+3 Close: **−71.0 bp (OOS −108.0 bp)**
- 종가 매수 후 다음날 시가에 나가지 않고 장중이나 다음날까지 들고 가면, 시초가 직후 쏟아지는 차익실현 매물(-61bp)과 거래세 누적으로 손실이 급격히 불어난다.
- 따라서 **청산의 기준선(Default Exit)은 반드시 `D+1 Open`으로 고정 유지**되어야 한다.

### 질문 4. D+2/D+3 short-term strategy로 확장할 근거가 있는가?
**답변: 전혀 없다 (REJECT). 데이터는 D+2/D+3 확장을 명백하게 기각한다.**

1. **점증 기대수익률이 완벽히 음수**:
   - D+1 종가에서 D+2 종가로 갈 때 -15.6bp 손실, D+2에서 D+3 갈 때 -8.9bp 추가 손실.
2. **자본 효율성 붕괴**:
   - 자본일당 수익률: D+1 (+137bp) → D+2 (+63bp, -54%) → D+3 (+39.5bp, -71%).
   - 포트폴리오 CAGR: D+1 (+345%) → D+2 (+158%) → D+3 (+99.5%, -71%).
3. **리스크 4배 폭증**:
   - 95% CVaR(꼬리 위험)이 -5.86%에서 -22.46%로 4배 악화.
   - 최대 불리 변동(MAE)이 -3.8%에서 -7.4%로 2배 증가.
4. **모델 불일치**:
   - 모델 스코어의 Rank IC가 D+1 Open(0.37)에서 D+3 Close(0.08)로 78% 소실되어 예측 불가능한 영역.

### 질문 5. 문제의 핵심은 무엇인가?
**답변: 문제의 본질은 '청산 시점'이 아니라 '진입 유니버스의 정점 통과(Post-Peak)'와 '체결 비용 구조'이다.**

1. **Entry Universe 결함 (1순위)**:
   - 기존 `>=10%` 유니버스는 이미 시장 참여자들의 관심이 극에 달해 차익실현이 시작되는 **알파 피크 이후 구간**이다.
   - 오버나이트 Gross 에지는 **`5~10%` 구간에서 +30.9bp로 정점**을 찍고, 10~15% (+25.6bp) → 15~20% (+16.3bp) → 20~25% (−12.3bp)로 급격히 붕괴한다.
2. **거래비용의 구조적 장벽 (2순위)**:
   - 오버나이트 총 에지가 +30bp인데, 법정 세금(20bp)과 시장가 슬리피지/스프레드(26bp) 합계가 46bp이다.
   - 즉, **시장가 체결 구조를 유지하는 한 어떤 모멘텀 종목을 골라도 장기적으로 수수료를 이길 수 없다**.
3. **청산 규칙의 왜곡 (3순위)**:
   - 정상적 장중 변동성(중간값 -3.11%)을 무시하고 도입한 정적 손절(3~5%)이 바닥 청산을 강제해 일평균 -50~-95bp의 손실을 누적시킴.

   - 실측 결과: 5~10%가 피크이며, 10% 이상은 차익실현 매물 폭탄 구간임 (기각).
2. **가설 기각 2: "D+2나 D+3까지 며칠 더 들고 가면 추세가 이어져 수익이 극대화된다"**

### 질문 7. 추가 검증 가치가 높은 가설은 무엇인가?
