# ML 재학습 비교 보고서 (2026-08-05)

## 결론

새 구현으로 재학습한 결과는 기존 보고서의 수익률보다 낮아졌다. 이는 실패라기보다, 기존의 49개 피처 중 주문 시점이 증명되지 않은 캔들/실현 매수가 파생 피처를 제외하고, 타깃을 `%`가 아닌 **decimal net return**으로 정규화한 결과다. 현재 데이터에는 실제 스냅샷 캡처 시각이 없으므로 이번 결과는 point-in-time 검증을 통과한 실거래 성과가 아니다.

현재 기준으로는 `LGBMRegressor`가 `LGBMRanker`보다 OOF Top-1이 높지만, 둘 다 2026년 구간에서 음수다. 모델을 운영 번들로 승격하지 않고, 캡처 시각이 있는 paper-trading 검증을 먼저 진행해야 한다.

## Quantile·확률·Sizing 비교

| 지표 | 기존 | 신규 |
| --- | ---: | ---: |
| q10–q90 nominal 80% coverage | 69.7% | **77.4%** |
| 평균 구간 폭 | 6.377%p | 7.616%p |
| p_good Brier | 0.2454* | 0.2203 |
| p_bad Brier | 0.2455* | 0.1885 |

`*` 기존 Brier는 ±0.01/±0.015 percentage-point 라벨을 사용해 신규 +1%/−2% decimal-net 라벨과 직접 비교할 수 없다. 신규 calibration fold 진단에서는 `p_good` Brier가 date-prior baseline보다 모든 fold에서 낮지 않았다. 즉, 확률 보정은 구현됐지만 아직 확률 알파를 입증하지 못했다.

신규 OOF sizing 결과는 Pass 30,118건(96.67%), Strong 541건, Good 438건, Weak 59건이다. 기존 최신 일일 추론의 Pass 91.4%와는 모집단이 달라 직접 비교할 수 없다.

## 중요 해석 및 남은 위험

1. 이번 실행은 `decision_timestamp == feature_available_timestamp`를 합성해 통과시켰다. 실제 원천 parquet에 캡처 시각이 없기 때문에 누수 제거를 증명한 것이 아니다.
2. 신규 `cost_adjusted_return`는 net target에 비용을 다시 차감하지 않도록 수정했다. 따라서 신규 Top-1 값 자체가 비용 차감 후 수익률이다.
3. Ridge baseline은 실데이터의 결측 수치 피처를 train-fold 중앙값(전부 결측이면 0)으로 대체한다. 검증 폴드 정보는 사용하지 않는다.
4. 신규 OOF regime breakdown은 OOF frame에 시장구분/시가총액 컬럼을 아직 전달하지 않아 비어 있다. regime 안정성 분석을 완성하려면 다음 구현에서 해당 컬럼을 fold frame에 보존해야 한다.
5. 새 bundle은 비교용으로 `/tmp/ml_rerun_bundle/sizing_pipeline_bundle.joblib`에 저장했으며 기존 `artifacts/models` 번들은 덮어쓰지 않았다.

## 판단

새 구현은 기존 결과의 과장 가능성을 줄였고, 타깃 단위·baseline·quantile coverage가 개선됐다. 그러나 실제 예측력은 기존보다 낮으며 2026년 성과가 음수다. 현재 승자는 `LGBMRegressor` 후보지만 승격 판정은 보류한다. 다음 필수 단계는 실제 주문 전 캡처 시각을 저장한 뒤, 완전히 사용하지 않은 기간의 paper-trading OOS에서 Ranker/Regressor/Ridge/선정순위를 같은 비용·체결 규칙으로 비교하는 것이다.
